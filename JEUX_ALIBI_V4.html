📋 Règles du jeu
1Entrez les noms des 4 joueurs (2 binômes : Équipe A et Équipe B).
2Chaque équipe reçoit un scénario différent. Les partenaires lisent ensemble et se mettent d'accord sur des détails précis. Le minuteur aide à rester dans le temps.
3L'Inspecteur A interroge séparément le joueur n°1 de chaque équipe, puis l'Inspecteur B interroge les joueurs n°2. Chaque suspect répond à 10 questions sans voir les réponses de son partenaire.
4Score : +1 point si les 2 réponses du binôme sont identiques. L'équipe avec le plus de réponses qui correspondent gagne !
💡 Conseil : répondez court et précis — "bracelet rouge", "table du fond à gauche".

🌐 Mode en ligne — Comment ça marche ?
À quoi sert ce mode ?
Le mode en ligne ne connecte pas des inconnus à travers le monde. Il sert à synchroniser deux ordinateurs dans la même partie — chaque écran représente un inspecteur. L'un crée la partie, l'autre la rejoint avec un code, et les deux écrans se pilotent en temps réel.
① Connexion — Le Lobby
Écran Hôte (toi)
Menu → En ligne → entre ton prénom → Créer
Un code de partie s'affiche — envoie-le à ton pote.
Écran Invité (ton pote)
Menu → En ligne → entre son prénom → colle le code → Rejoindre
✔ Les deux noms apparaissent (Inspecteur A + Inspecteur B)
✔ L'invité clique Prêt
✔ Le bouton Lancer la manche s'active côté hôte uniquement → toi tu cliques
② Phase Préparation
✔ Les deux écrans voient les scénarios Équipe A en même temps
✔ Chacun peut naviguer vers Équipe B indépendamment sans affecter l'autre
✔ Le bouton Lancer l'interro n'apparaît que sur l'écran hôte
✔ Quand tout le monde a lu → hôte clique Lancer l'interro → décompte 3-2-1 sur les deux écrans
③ Phase Interrogatoire
✔ Les deux écrans entrent dans la partie au même moment
✔ La synchronisation hôte/invité continue pendant toute la partie
